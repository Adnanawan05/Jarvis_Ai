STEP 1: SETUP (First Time Only - Takes 2-3 minutes)
───────────────────────────────────────────────────────────────

    Linux / Mac:
    ──────────────────────────────────────────────────────
    $ chmod +x setup.sh run.sh
    $ ./setup.sh
    ──────────────────────────────────────────────────────

    Windows:
    ──────────────────────────────────────────────────────
    > setup.bat
    ──────────────────────────────────────────────────────

    What it does:
    • Installs Node.js dependencies (Electron, etc.)
    • Installs Python dependencies (FastAPI, etc.)
    • Creates configuration files
    • Sets up directories


STEP 2: RUN (Every Time - Takes 5-10 seconds)
───────────────────────────────────────────────────────────────

    Linux / Mac:
    ──────────────────────────────────────────────────────
    $ ./run.sh
    ──────────────────────────────────────────────────────

    Windows:
    ──────────────────────────────────────────────────────
    > run.bat
    ──────────────────────────────────────────────────────

    What it does:
    • Starts backend server (Python FastAPI)
    • Starts frontend application (Electron)
    • Opens JARVIS window
    • You're ready to use it!


STEP 3: ENJOY! 🎉
───────────────────────────────────────────────────────────────

When JARVIS opens, you'll see:
✓ Animated particle background
✓ Holographic AI avatar
✓ Real-time system monitoring
✓ Interactive control panels

Try these first commands:
• Click Voice panel (🎤)
• Say: "Jarvis, hello"
• Say: "Jarvis, what's my system status?"
• Or type commands manually

Navigate with keyboard:
• Ctrl/Cmd + 1-7 = Switch panels
• Ctrl/Cmd + K = Command input
• Ctrl/Cmd + L = Voice toggle

                    ⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Setup fails
Solution: Check Node.js and Python are installed
          node --version (should be 18+)
          python3 --version (should be 3.10+)

Problem: Backend won't start
Solution: Check if port 8000 is in use
          Kill any process using that port

Problem: Frontend won't open
Solution: Try running manually: npm run dev
          Check logs/frontend.log for errors

Problem: Voice not working
Solution: Grant microphone permissions
          Use manual text input as alternative
